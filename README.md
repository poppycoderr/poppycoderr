## Open source

### 🛡️ [Grounded Access](https://github.com/poppycoderr/grounded-access)

**Permission-aware, evaluation-driven retrieval for enterprise knowledge.**

A Java and Python reference system exploring how authorization, retrieval quality and reproducibility fit together. The current walking skeleton includes tenant authorization inside PostgreSQL queries, PostgreSQL FTS, exact pgvector search, an offline CPU embedding service, a versioned evaluation dataset and a CI security gate.

Hybrid retrieval, the full ABAC decision table, reranking, cited answers and tracing are being developed and measured rather than presented as finished capabilities.

### 🧱 [Domain Driven Kit](https://github.com/poppycoderr/domain-driven-kit)

**Executable DDD for Spring Boot.**

A Java engineering toolkit that turns architectural conventions into reusable code and CI checks: domain model primitives, Spring Boot starters, MyBatis persistence, two-level caching, MCP integration, Maven archetypes and ArchUnit rules for three- and four-layer applications.

The project is designed to give developers and AI coding agents the same explicit guardrails.

### 📝 [codesphere](https://github.com/poppycoderr/codesphere)

**Technical notes from building and operating backend systems.**

My public knowledge base covers Java, Spring, databases, Redis, messaging, Elasticsearch, distributed architecture, AI tooling and the design decisions behind my open-source work.

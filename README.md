## About

I build backend systems that have to stay understandable under real production pressure: high concurrency, large tables, search, messaging, cloud deployment and operational troubleshooting.

My core background is **Java / Spring Boot / Spring Cloud**, with recent production work in **Python / FastAPI / AWS**. I also work on **LLM and RAG applications**, especially enterprise knowledge systems that combine retrieval, knowledge graphs and backend orchestration.

Current focus:

- Backend architecture for fintech and enterprise platforms
- Java and Python services on cloud-native infrastructure
- DDD, layered architecture and practical engineering conventions
- Search, SQL optimization, Redis, Kafka and consistency trade-offs
- AI-assisted backend workflows, RAG and agent-oriented system design

## Featured Work

### Domain Driven Kit

**Java DDD scaffolding and starter toolkit.**

`domain-driven-kit` is my long-running open-source project for turning DDD ideas into executable Java conventions: layered project structure, common response and exception contracts, pagination, mapper abstractions, MyBatis-Plus repository support, Spring Boot starters and architecture guard rules.

- Repository: [domain-driven-kit](https://github.com/poppycoderr/domain-driven-kit)
- Documentation: [DDK docs](https://poppycoder.netlify.app/#/docs/ddk/index.md)
- Current direction: engineering baseline, domain model primitives, starter normalization and runnable examples

### codesphere

**Personal engineering notes and documentation site.**

`codesphere` collects my notes on backend engineering, Java, middleware, architecture, AI/LLM integration and DDK. I use it as a public knowledge base and as a place to turn production lessons into reusable engineering documents.

- Site: [codesphere](https://poppycoder.netlify.app)
- Topics: Java, backend practice, Redis, MySQL, Elasticsearch, RabbitMQ, architecture, AI tooling

### Enterprise AI and Backend Systems

Some professional work cannot be shared as source code because of corporate IP restrictions, but the engineering themes are reflected in my public writing and DDK:

- Enterprise RAG platform with LLM workflows, Elasticsearch, knowledge graphs and retrieval orchestration
